## AI 활용

이 프로젝트의 코드는 **2학기 데모 준비부터 대부분 AI 코딩 도구(Claude Code)로 작성**했습니다. 직접 구현한 부분은 1학기의 플레이어 구조입니다.
제가 맡은 일은 무엇을 만들지 정하는 것, 만들어진 결과를 플레이해서 문제를 가려내는 것(QA), 계획을 승인하고 선택지를 고르는 것이었습니다.
AI 비중이 커서 2학기에 쌓인 구조를 아직 다 장악하지 못했고, 출시 후 구조를 읽으며 정리하는 중입니다. 빠르게 만드는 과정에서 쌓인 기술 부채가 있고, 출시 전에는 리팩토링하지 않았습니다.
작업 규칙(계획 승인 후 수정, 새 문제는 `TODO.md`에만 등록 등)과 사례는 포트폴리오 페이지에 정리해 두었습니다.

## 먼저 볼 코드

기준 폴더는 `Source/US/`입니다.

- **편대 · 진형** — 대장 이동 방향 기준 슬롯 오프셋으로 진형을 짜고, 진형이 천천히 따라 돌게 합니다. 격추 · 부활 · 편대 강화를 기록해 두었다가 나중에 스폰되는 부하에도 다시 적용합니다
  - `Components/USSquadComponent.h`
- **아군 · 적 등록부** — 월드 서브시스템에 스스로 등록 · 해제하게 해서, 가장 가까운 상대를 매 프레임 `GetAllActorsOfClass` 없이 조회합니다
  - `Core/USTeamSubsystem.h`
- **풀링과 이펙트 상한** — 총알은 `SpawnActor`/`Destroy` 대신 풀에서 꺼내 쓰고, 폭발 이펙트는 종류별 동시 재생 수를 제한해 넘치면 가벼운 판으로 대신 터뜨립니다
  - `Core/USBulletPoolSubsystem.h` · `Core/USFXBudgetSubsystem.h`
- **메타 진행** — 판 사이에 남는 스크랩 · 영구 업그레이드 · 기록을 `GameInstance` 서브시스템이 들고 저장합니다. 맵을 옮겨도 사라지지 않습니다
  - `Progression/USMetaProgressionSubsystem.h`
- **데이터 에셋** — 숫자는 데이터 에셋에, 모양은 블루프린트에 둬서 부하기 종류를 코드 수정 없이 늘릴 수 있게 했습니다
  - `Datas/USAllyTypeData.h`
